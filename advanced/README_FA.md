# آموزش سراسری پارامتری روی Kaggle

این نسخه یک مدل تازه است؛ وزن‌ها و نتایج نسخهٔ قبلی را تغییر نمی‌دهد. آموزش فقط روی سه حالت انجام نمی‌شود: در هر گام، ترکیب‌های تصادفی از کل دامنهٔ مجاز پارامترها وارد می‌شوند. سه حالت زیر صرفاً برای خروجی‌های قابل مقایسه در هر ۱۰۰۰ گام هستند.

| پارامتر | کف | پایه | سقف |
|---|---:|---:|---:|
| Rin | 0.02 | 0.2 | 2 |
| Rout | 0.05 | 0.5 | 5 |
| Re | 0.1 | 1 | 10 |
| قطر ذره | 0.0025 | 0.025 | 0.25 |
| نسبت چگالی | 100 | 1000 | 10000 |

بازهٔ مورد درخواست **۰٫۱ تا ۱۰ برابر پایه** است؛ از نظر درصدی یعنی ۹۰٪ کاهش تا ۹۰۰٪ افزایش. کمیت‌ها بی‌بُعدند؛ برای SI باید L0، U0، چگالی و ویسکوزیته سازگار تعیین شوند.

## دامنهٔ آموزش و شبکه

پنج پارامتر مثبت به‌صورت یکنواخت در لگاریتم نمونه‌برداری می‌شوند. ترکیب‌های نامعتبر رد می‌شوند: Rin باید از Rout کوچک‌تر باشد، h/R نباید از ۰٫۸۵ بیشتر شود و قطر ذره باید از عرض کانال کمتر باشد. بنابراین دامنه، بخش مجاز جعبهٔ پارامترهاست؛ همهٔ گوشه‌های مستقل آن قابل اجرا نیستند. هر پنج متغیر بازهٔ یک‌دهم تا ده‌برابر دارند، اما مستقل‌گرفتن تمام ترکیب‌ها بدون این قیود ممکن نیست.

مختصات x,y در کانال همان حالت نمونه‌برداری می‌شوند. سرعت و فشار، خروجی میدان جریان‌اند؛ آن‌ها را نمی‌توان مستقل از معادلات برابر ۱۰ برابر مقادیر پایه قرار داد. ورودی واقعی شبکهٔ جریان:

`[x/R−2, y/R, log10(Rin/0.2), log10(Rout/0.5), log10(Re/1)]`

شبکهٔ پیش‌فرض ۶ لایهٔ پنهان ۱۲۸ نورونی tanh و خروجی u,v,p دارد. سرعت دیواره و پروفیل سهموی هر دو مقطع انتهایی به صورت سخت اعمال می‌شوند. فشار یک مرجع نقطه‌ای در خروجی دارد. مشتق‌ها نسبت به مختصات واقعی x,y گرفته می‌شوند و loss شامل ناویر–استوکس پایا، پیوستگی و قید انتگرالی دبی است. پارامترهای هندسه و Re در هر گام تغییر می‌کنند.

قطر و چگالی در مدل یک‌طرفه روی میدان جریان اثر ندارند؛ در معادلهٔ حرکت ذره وارد می‌شوند. در این نسخه برای درگ از رابطهٔ صریح Schiller–Naumann استفاده شده و شبکهٔ نیروِ نسخهٔ قبلی در حل حرکت به کار نمی‌رود. قانون صریح، خطای تقریب نیروی شبکهٔ قدیمی را به این آزمایش اضافه نمی‌کند. برای Rep کمتر از ۱۰۰۰ ضریب اصلاح برابر `1+0.15 Rep^0.687` و پس از آن `Cd=0.44` است. مدل ذره کروی منفرد است: اثر لیفت، گرانش، بازخورد ذره به سیال، تصحیح نزدیک دیواره و برهم‌کنش ذرات لحاظ نشده‌اند. برای ذرات بزرگ نسبت به عرض، این تقریب می‌تواند ناکافی باشد؛ صرف قرارگرفتن در دامنهٔ هندسی تضمین اعتبار فیزیکی نیست.

۶۰٬۰۰۰ گام AdamW با نرخ اولیهٔ ۰٫۰۰۰۸ و کاهش cosine تا ۰٫۰۰۰۰۱، نمونه‌های داخلی ۱۰۲۴ و curriculum با بازشدن تدریجی دامنه طی ۱۰٬۰۰۰ گام در نظر گرفته شده‌اند. سه حالت مرجع از ابتدا نیز در batchها حضور دارند. این بودجه تضمین همگرایی نیست. فایل `settings.json` قابل تنظیم است؛ تغییر تنظیمات اصلی در میانهٔ یک مطالعه پذیرفته نمی‌شود.

## خروجی هر ۱۰۰۰ گام

`advanced_runs/<run-id>/snapshots/step_001000/` و سپس step_002000 و ... شامل موارد زیر خواهند بود:

- `three_cases.png/.pdf`: میدان سرعت و مسیر چند ذره برای کف، پایه و سقف.
- `particle_motion.gif`: حرکت همان ذرات با موقعیت‌های شروع تصادفی ثابت برای مقایسهٔ گام‌ها. هر پنل ساعت فیزیکی خودش را نشان می‌دهد.
- `particle_paths.csv`: زمان، موقعیت، سرعت و سرنوشت ذرات.
- `metrics.json`: خطای سرعت و فشار در برابر FEM مستقل و مقایسهٔ هم‌زمان مسیرهای ذرات، در صورت موفقیت مرجع.
- `training_history.csv` و `loss.png`: تاریخچهٔ آموزش.
- `export_errors.json` و `complete.json`: خطاهای خروجی‌گیری و کامل‌بودن snapshot.

نقاط ذرات برای هر حالت تصادفی اما با بذر ثابت‌اند و در تمام checkpointها یکسان می‌مانند. برخورد چسبنده در فاصلهٔ شعاع ذره از دیواره، خروج، اتمام زمان و شکست عددی جدا ثبت می‌شوند. مرجع FEM آموزش را هدایت نمی‌کند. این سه ارزیابی به‌تنهایی صحت تمام دامنهٔ پارامتری را ثابت نمی‌کنند. شکست مرجع به‌عنوان «مرجع ناموجود» باقی می‌ماند؛ نتیجهٔ PINN جایگزین آن نمی‌شود.

`checkpoint.pt` در ریشهٔ مطالعه شامل وزن‌ها، AdamW، scheduler، شمارهٔ گام، تاریخچه و وضعیت مولدهای تصادفی است. ادامه از صفر نیست. checkpointها به دلیل pickle فقط باید از خروجی قابل اعتماد همین گردش‌کار بارگیری شوند.

## اتصال انتخاب‌شده: GitHub Actions، بدون توکن گیت‌هاب در Kaggle

آموزش یک اجرای پیوستهٔ GPU تا گام ۶۰٬۰۰۰ است. هر ۱۰۰۰ گام، checkpoint کامل در صف محلی ذخیره می‌شود و GPU بلافاصله ادامه می‌دهد. یک پردازش CPU مستقل، سه مرجع FEM را فقط یک‌بار آماده می‌کند، شکل‌ها و GIF را می‌سازد و هر snapshot را به یک نسخهٔ جدید Dataset خصوصی Kaggle می‌فرستد. این پردازش از مجوز داخلی همان حساب در runtime رسمی Kaggle استفاده می‌کند؛ توکن گیت‌هاب یا Secret جدیدی داخل نوت‌بوک لازم نیست. Dataset همهٔ نسخه‌ها را نگه می‌دارد تا خروجی‌های میانی حذف نشوند.

GitHub Actions هر ۳۰ ثانیه نسخه‌های آماده را بررسی می‌کند، SHA256 بسته و هش کد را تطبیق می‌دهد و snapshotها را به ترتیب زیر `advanced_runs/` commit می‌کند. ذخیره در GitHub منتظر پایان آموزش نمی‌ماند. ساخت شکل و پردازش Dataset تأخیر دارند؛ زمان انتشار دقیقاً برابر لحظهٔ رسیدن GPU به مضرب ۱۰۰۰ نیست. snapshot از کپی ثابت وزن‌های همان گام ساخته می‌شود. کندی یا شکست انتشار حلقهٔ GPU را متوقف نمی‌کند و فایل‌ها برای بازیابی در خروجی Kaggle می‌مانند.

1. Secret مخزن با نام `KAGGLE_API_TOKEN` برای Actions لازم است؛ آن را فقط در **Settings → Secrets and variables → Actions** وارد کنید.
2. در **Actions → Parametric Kaggle training → Run workflow**، `start_new` را فقط برای آغاز یک مطالعهٔ تازه فعال کنید. بدون آن مطالعهٔ فعال بررسی می‌شود.
3. کنترل‌گر تا ۵٫۵ ساعت فعال است و زمان‌بندی ده‌دقیقه‌ای پشتیبان آن است. پایان کنترل‌گر اجرای GPU را قطع نمی‌کند. وضعیت Dataset، شمارهٔ نسخه، آخرین گام دریافت‌شده و شناسهٔ اجرای GPU در `advanced/run_state.json` ثبت می‌شوند.
4. در نسخهٔ تولیدی GPU هیچ unit test اجرا نمی‌شود؛ تست‌ها پیش از انتشار کد محلی اجرا می‌شوند. بسته‌های موجود دوباره نصب نمی‌شوند و نصب فقط برای وابستگی ناسازگار یا غایب انجام می‌شود.

workflow از `GITHUB_TOKEN` خودکار و محدود به همین مخزن برای commit استفاده می‌کند. checkpoint شروع از آدرس عمومی مخزن با SHA ثابت commit دریافت و SHA256 آن بررسی می‌شود؛ مخزن فعلی عمومی است. وزن‌ها، AdamW، scheduler و RNG حفظ می‌شوند. مهاجرت از اجرای قطعه‌ای قبلی فقط پس از تطبیق وابستگی‌های فیزیکی و AST الگوریتم آموزش با `advanced/upgrade_continuous.py` مجاز است؛ گزارش آن در `advanced/continuous_migration.json` ثبت شده است. هیچ تغییری در معادلات، شبکه، نرخ یادگیری یا نمونه‌برداری این مهاجرت اعمال نمی‌شود.

برای توقف، اجرای فعال را در Kaggle لغو و مقدار status در `advanced/run_state.json` را `paused` کنید؛ لغو فقط یک اجرای Actions مانع polling بعدی نیست. برای ادامه پس از وقفه، checkpoint قبلی را حفظ و پس از بررسی وضعیت اجرای قبلی، status را ready تنظیم کنید. از شروع مطالعهٔ دوم روی یک مطالعهٔ فعال جلوگیری می‌شود.

## بررسی محلی و بازتولید

```bash
python -m unittest discover -s tests -p test_parametric.py -v
python run_parametric_pinn.py --device cpu --total-steps 2 --chunk-steps 1 --snapshot-every 1 --samples 32 --width 16 --depth 2 --curriculum-steps 1 --particles 2 --reference-ns 18 --reference-nn 6 --out results/advanced_smoke_1
python run_parametric_pinn.py --device cpu --total-steps 2 --chunk-steps 1 --snapshot-every 1 --samples 32 --width 16 --depth 2 --curriculum-steps 1 --particles 2 --reference-ns 18 --reference-nn 6 --resume results/advanced_smoke_1/checkpoint.pt --out results/advanced_smoke_2
```

برای اجرای بلند، تنظیمات پیش‌فرض و GPU استفاده شوند. مدل صرفاً کانال S دوبعدی با عرض ثابت را پوشش می‌دهد؛ حل سه‌بعدی کانال و شکل دلخواه در این نسخهٔ پارامتری ادعا نمی‌شود.
