# Export smoke demonstration

These artifacts are from **two CPU optimizer steps**, a **2x16** test network and **two particles**, with an **18x6 FEM mesh**. They verify the export pipeline only. They are not the planned 60,000-step GPU study and are not publication validation. The production defaults are 6x128, five particles and a 64x14 reference mesh.

Three cases are shown (all parameters divided by ten, baseline, and multiplied by ten). Animated panel clocks are independent; velocity units are U0.
