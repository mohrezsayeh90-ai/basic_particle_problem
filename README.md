## اجرا

پروژه با Python 3.12 آزمایش شده است. روی این محیط، مفسر آماده در `/workspace/.venvs/particle/bin/python` قرار دارد.

```bash
python -m venv .venv
source .venv/bin/activate
# CPU; برای CUDA نسخهٔ مناسب PyTorch را مطابق راهنمای رسمی نصب کنید.
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python run_particle_pinn.py --preset quick
```

برای آموزش طولانی‌تر و خروجی‌های چند بذر تصادفی:

```bash
python run_particle_pinn.py --preset standard --out results/standard_01
python run_particle_pinn.py --preset paper --device auto --out results/paper_01
```

`quick` برای بررسی اجرای سرتاسری است؛ دقت مقاله را تضمین نمی‌کند. `paper` نیز فقط بودجهٔ آموزش، اندازهٔ شبکهٔ مرجع و تعداد بذرها را بیشتر می‌کند. معیارهای `metrics.json`، حساسیت شبکه و نتایج مستقل باید بررسی شوند. نتایج تولیدشده را بدون این بررسی به‌عنوان نتیجهٔ تأییدشدهٔ مقاله ارائه نکنید.

برای بازتولید ارزیابی و تصاویر یک اجرای کامل، می‌توانید وزن‌ها را دوباره استفاده کنید. هندسه، Re و تنظیمات بذر باید با اجرای مبدأ سازگار باشند؛ `--seeds` را مطابق آن تنظیم کنید. مدل دوباره آموزش نمی‌بیند و checksum وزن‌ها و تنظیمات آموزش اولیه در گزارش نگهداری می‌شود:

```bash
python run_particle_pinn.py --preset standard --seeds 3 --weights-from results/standard_01 --out results/evaluation_01
```

`python assess_results.py results/evaluation_01` فقط جدول معیارها و گزارش را از داده‌های موجود بازسازی می‌کند و پیش‌بینی‌ها را تغییر نمی‌دهد. معیار موفقیت حل‌گر مسیر از معیار توافق سرنوشت، خطای مکانی و پوشش زمانی مسیرها جداست. فشار و سرعت آزمون سه‌بعدی هم جدا ارزیابی می‌شوند. کوچک بودن خطای متوسط میدان، به‌تنهایی صحت رسوب ذرات نزدیک دیواره را تأیید نمی‌کند.

خطاهای نسبی L₂ در گزارش از نمونه‌های مکانی مستقل محاسبه می‌شوند؛ این‌ها نرم گسستهٔ نمونه‌ها هستند و انتگرال دقیقِ وزن‌دار مساحت نیستند. در معیار فشار Poiseuille، نمونه‌ها در طول کانال پخش می‌شوند؛ مقایسهٔ فشار تنها روی یک مقطع ثابت برای این معیار معنی‌دار نیست.

خروجی پیش‌فرض هر بار در پوشهٔ جدیدی زیر `results/` ساخته می‌شود. پوشهٔ غیرخالی بازنویسی نمی‌شود. برای اطلاع از همهٔ گزینه‌ها از `--help` استفاده کنید. آموزش Adam با L-BFGS تکمیل می‌شود؛ `--lbfgs-steps 0` این مرحله را غیرفعال می‌کند.

## مدل و ساختار شبکه

دو شبکه مطابق طرح ارائه‌شده:

| شبکه | ورودی | لایه‌های پنهان | خروجی |
|---|---|---|---|
| FlowNet | x, y, Rin, Rout, Re | 5 × 70، tanh | u, v, p |
| ForceNet | u, v, p, dp, xp, yp, up, vp | 5 × 90، tanh | Fx, Fy |

برای هر هندسه و Re، شبکهٔ جریان جدا آموزش می‌بیند. وجود ورودی پارامتر به‌تنهایی به معنی تعمیم به پارامترهای آموزش‌ندیده نیست. دادهٔ داخل دامنه از FEM در آموزش شبکهٔ جریان استفاده نمی‌شود. loss شامل معادلات، شرایط مرزی، مرجع فشار و قید انتگرالی بقای جرم است. انتخاب checkpoint با loss فیزیکی روی نمونه‌های ثابت انجام می‌شود؛ اولین بذر برای نتایج اصلی استفاده می‌شود و بهترین بذر با نگاه به مرجع انتخاب نمی‌شود.

معادلات بی‌بُعد جریان:

```text
∇ · u = 0
Re (u · ∇) u = −∇p + ∇²u
```

در ورودی و خروجی، پروفیل سهموی با سرعت مرکزی واحد و جهت مماس به خط مرکزی اعمال می‌شود؛ دیواره‌ها بدون لغزش‌اند و فشار یک مرجع ثابت دارد. این شرایط «سرعت در دو انتها» هستند، نه شرط خروج فشار صفر یا جریان کاملاً توسعه‌یافته در خروجی. حل مرجع دقیقاً همین شرایط را دارد.

برای ذرات:

```text
dxp/dt = vp
dvp/dt = 18 (u(xp) − vp) / (ρratio Re dp²)
St = ρratio Re dp² / 18
Rep = Re dp |u − vp|
```

مدل پیش‌فرض: سیال نیوتنی تراکم‌ناپذیر، جریان پایا و آرام، ذرات کروی رقیق با چگالی زیاد و کوپل یک‌طرفه. وزن، برآ، نیروی براونی، تاریخچهٔ بَسِت، جرم افزوده و برهم‌کنش ذره–ذره در این مدل نیستند. بنابراین عنوان «interaction» در این پیاده‌سازی به درگ سیال–ذره و تماس با دیواره اشاره دارد. ForceNet تقریب قانون مشخص استوکس را از residual جبری آن می‌آموزد؛ ادعای کشف قانون نیروی جدید ندارد. در حد لغزش صفر، خروجی نیرو دقیقاً صفر است.

مرکز ذره در فاصلهٔ شعاع ذره از دیواره متوقف می‌شود و برخورد کاملاً چسبنده است. برای سیال، انتگرال‌گیری `dx/dt = u(x)` انجام می‌شود. حل‌گر بر اساس زمان آسایش، RK45 یا Radau را انتخاب می‌کند. خروج از ورودی/خروجی، برخورد، اتمام زمان و شکست عددی جدا ثبت می‌شوند. ذرات خارج‌شده در انیمیشن حذف می‌شوند و ذرات چسبیده در محل برخورد می‌مانند.

طول، سرعت، زمان و فشار به‌ترتیب با L₀، U₀، L₀/U₀ و μU₀/L₀ مقیاس شده‌اند. `Re = ρf U₀L₀/μ` است؛ L₀ به‌صورت ضمنی قطر هیدرولیکی نیست. نیروی خروجی با `ρf (πdp³/6) U₀²/L₀` مقیاس می‌شود. برای تبدیل به SI باید مقیاس‌ها و خواص فیزیکی سازگار انتخاب شوند.

## هندسه و حالت‌های مختلف

پیش‌فرض، کانال S شامل دو نیم‌دایره است. `Rin=0.2` و `Rout=0.5`؛ شعاع خط مرکزی متوسط این دو و عرض کانال اختلاف آن‌هاست. اتصال دو قوس مماس پیوسته و انحنای قطعه‌ای دارد. مرجع FEM دیواره را به‌صورت چندضلعی تقریب می‌زند؛ حساسیت هندسه همراه با حساسیت شبکه گزارش می‌شود.

```bash
python run_particle_pinn.py --preset quick --geometry straight
python run_particle_pinn.py --preset quick --geometry bend --re 3
python run_particle_pinn.py --preset standard --centerline examples/centerline.csv
python run_particle_pinn.py --preset standard --re 2 --diameter 0.02 --density-ratio 800
python run_suite.py --preset quick --out results/geometry_suite
```

پس از آموزش، برای شروع از هر نقطهٔ مجاز داخل کانال، نیازی به آموزش مجدد نیست:

```bash
# نمونه برای کانال S پیش‌فرض؛ نقطه داخل بخش نخست کانال است.
python trace_path.py --run results/standard_01 --start 0.35 0.35 --tracer --out results/custom_tracer
python trace_path.py --run results/standard_01 --start 0.35 0.35 --velocity 0 0 --out results/custom_particle
# انتخاب صریح مرجع عددی به‌جای شبکه:
python trace_path.py --run results/standard_01 --start 0.35 0.35 --reference --out results/custom_reference
```

رابط پایتونی همین کار در `particle_pinn.api.load_run` و `particle_pinn.api.trace` در دسترس است. نقطهٔ شروع باید واقعاً داخل دامنه و با فاصلهٔ کافی برای شعاع ذره باشد. تغییر هندسه یا Re به آموزش تازه نیاز دارد؛ صرفاً تغییر نقطهٔ شروع چنین نیازی ندارد.

خط مرکزی دلخواه: CSV با سرستون `x,y` و حداقل چهار نقطهٔ مرتب. کد آن را با spline و عرض ثابت تبدیل به کانال می‌کند. مسیر باید صاف، بدون تقاطع و با شعاع انحنای کافی نسبت به عرض باشد. دامنه‌های منشعب، گوشهٔ تیز، عرض متغیر و هندسهٔ دلخواه سه‌بعدی در این نسخه پشتیبانی نمی‌شوند. مختصات شروع مسیرهای سفارشی می‌تواند هر جایی باشد. درگ استوکس زمانی مناسب است که `Rep ≪ 1` و قطر ذره نسبت به عرض کانال کوچک باشد؛ `max_particle_re` برای هر مسیر ذخیره می‌شود. معتبر بودن فرض رقیق به بارگذاری واقعی ذرات بستگی دارد.

## اعتبارسنجی

1. حل تحلیلی Poiseuille صفحه‌ای: `u=1−(y/h)²`, `v=0`, `p=−2x/h²+C`. هم FEM و هم یک PINN مستقل کانال مستقیم با آن مقایسه می‌شوند.
2. حل مستقل Navier–Stokes با اجزای محدود Taylor–Hood P2/P1 در scikit-fem، تکرار Picard و حل مستقیم sparse. این حل از پیش‌بینی PINN مستقل است. نام نرم‌افزار تجاری CFD یا دادهٔ آزمایشگاهیِ استفاده‌نشده به آن نسبت داده نمی‌شود.
3. سه شبکهٔ FEM: اختلاف سرعت با بهترین شبکهٔ موجود، residual غیرخطی و نرم واگرایی. اختلاف شبکه‌ها تخمین حساسیت است، نه عدم‌قطعیت رسمی GCI.
4. داده‌های مکانی مستقل برای خطای میدان، مرز، شار و فشار پس از هم‌مرجع‌کردن فشار؛ آزمون force روی لغزش‌های خارج از batchهای آموزش و جواب دقیق آسایش استوکس.
5. مقایسهٔ مسیرها در بازهٔ زمانی مشترک، طول پوشش زمانی و تطابق سرنوشت ذره؛ مسیر `PINN + Stokes` برای تفکیک خطای ForceNet نیز محاسبه می‌شود.
6. چند بذر تصادفی با گزارش همهٔ نتایج. برای بررسی بیشتر می‌توان sweep هندسه/Re را جدا اجرا کرد.

مرجع رهگیری FEM با درون‌یابی در مختصات طولی/عرضی کانال ساخته می‌شود تا در خم‌ها از داخل حفره میان‌بُر نزند. خطای همین درون‌یابی نسبت به ارزیابی FEM نیز اندازه‌گیری می‌شود.

## سه‌بعدی

شکل `14_extruded_paths` نمایش فضایی یک حل دوبعدی است؛ عمق‌های ترسیمی فیزیکی نیستند و شاهد حل سه‌بعدی محسوب نمی‌شوند.

آزمون مستقل `19_3d_benchmark` یک PINN واقعی سه‌بعدی با خروجی u,v,w,p روی میدان ABC و نیروی حجمی مشخص دارد:

```text
u = sin(z) + cos(y)
v = sin(x) + cos(z)
w = sin(y) + cos(x)
p = −Re |u|²/2
f = u
Re (u · ∇)u = −∇p + ∇²u + f
```

چون میدان Beltrami و بدون واگرایی است، روابط بالا یک جواب دقیق ساخته‌شده می‌دهند. شبکه با residual و سرعت مرز آموزش می‌بیند؛ جواب داخل دامنه فقط در اعتبارسنجی استفاده می‌شود. مسیرها از خود میدان سه‌بعدی انتگرال گرفته می‌شوند. این benchmark، حل کانال سه‌بعدیِ عمق‌محدود را اثبات نمی‌کند. برای حذف این بخش `--skip-3d` و برای حذف GIF از `--skip-animation` استفاده کنید.

## فایل‌های پروژه

`particle_pinn/geometry.py`: هندسه؛ `fem.py`: مرجع مستقل؛ `models.py`: شبکه‌ها؛ `trajectories.py`: مسیرها و برخورد؛ `benchmark3d.py`: مسئلهٔ سه‌بعدی؛ `figures.py`: شکل‌ها. `tests/test_physics.py` معادلات، مرجع‌ها، معماری و رویدادهای دیواره را آزمایش می‌کند. راهنمای انگلیسی فرض‌ها و منابع علمی در هر `REPORT.md` ساخته می‌شود.

`Particle_PINN.ipynb` رابط اجرای نوت‌بوک و دانلود خروجی است. ابتدا ZIP پروژه را استخراج کنید و نوت‌بوک را در همان پوشه اجرا کنید. `scripts/setup.sh` نصب تکرارپذیر نسخه‌های CPU آزمایش‌شده را برای محیط ابری انجام می‌دهد.
